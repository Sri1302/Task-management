A basic Crud app using Nest Js

The main idea to create a Task Management System using NestJs

Routes:
createTask ,getAllTasks, getTaskById, getTaskbyQuery,updateTask, deleteTask

Concepts covered:
1.Created a custom model for task.
2. Instead of manually writing types we usually included types in DTO(Data transfer object).
3.I did not use any DB ,all data is stored in-memory. 
4. Used ValidationPipe against the DTO for validation of data.
